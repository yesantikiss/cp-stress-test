# ARC184 A の adaptive ジャッジ

[ARC184 A](https://atcoder.jp/contests/arc184/tasks/arc184_a) 用の interactor と解。問題はリンク先を読んでほしい。ここでは候補が多すぎる例として使う。

設定の要約: N = 1000 枚のコインのうち M = 10 枚が偽物。`? x y` と聞くと、x と y が同じ種類（両方本物か両方偽物）なら `0`、違えば `1` が返る。Q = 950 回まで聞けて、`! a_1 ... a_M` で偽物を全部答える。

偽物の集合は C(1000, 10) ≈ 2.6 × 10^23 通りあって並べられないので、`AdaptiveState` で状態を持つ。

- 状態: 返事でつながったコインの成分ごとに 2 色に塗り分け、色ごとの枚数 (a, b) を持つ（偶奇付き Union-Find）
- 点数: 偽物の集合としてありうる数。各成分で a 色か b 色のどちらかを全部偽物にして、合計がちょうど M になる選び方を DP で数える（`__int128` で収まる）
- 返事: 違う成分どうしなら 0 と 1 の両方を試し、ありうる数が多く残る方を返す。同じ成分なら矛盾しない方しか選べない（`apply` が `false` を返す）
- 判定: ありうる集合がちょうど 1 つで、答えと一致する

main.cpp は 19 枚と 21 枚の組を 25 個ずつ作り、組の中を順に聞いて（計 950 回）塗り分ける解。

組を全部 20 枚にすると、ある組が 10 枚と 10 枚に分かれたときにどちらが偽物か決まらない。そう書き換えた解は、この interactor だと 1 ケース目で「answer is not determined yet (2 sets left)」になる。

```bash
st -i -n 30
```
